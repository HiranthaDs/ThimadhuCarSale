# Welcome banner sports car slot

Place `welcome-sports-car.webp` in this directory, then restart Vite/rebuild.
Use a transparent-background, icy blue sports car in a side/front three-quarter
view, without a dark photographic background or strong outlines (about 780px wide).
Hero.jsx discovers the asset at build time and renders it decoratively with a
soft fade mask. Until supplied, the slot stays empty without broken images or 404s.
The existing sedan photograph is intentionally not substituted for this artwork.
