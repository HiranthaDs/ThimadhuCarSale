Video publishing guide

Add a Google Drive video

All Thimadu videos can stay in Google Drive. The website extracts the Drive file ID from the normal share link, creates a thumbnail automatically, and opens the video in the Google Drive player.
  1. 1

    Open the Thimadu video folder

    Use the Open video Drive button above, then upload the MP4/MOV video file to Google Drive.

  2. 2

    Set viewing permission

    Right-click the video → Share → General access → Anyone with the link → Viewer. Public visitors only need View permission; Edit permission is not required.

  3. 3

    Copy the normal Drive link

    A link such as https://drive.google.com/file/d/FILE_ID/view?usp=sharing is correct. Do not convert it to another URL.

  4. 4

    Create the Video entry

    Enter a clear headline, a useful description, paste the Drive link into Video link, choose display order/visibility, then Save video.

  5. 5

    Thumbnail is automatic

    For Google Drive videos the public site requests a Drive thumbnail automatically. If Drive does not generate one immediately, you may paste a custom public image URL in Custom thumbnail URL.

Important: test the Drive link in a private/incognito browser. If it asks the visitor to request access, the video is not public yet.
